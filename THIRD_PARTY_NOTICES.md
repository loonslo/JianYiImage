# Additional OCR components

The optional offline English/code recognition mode includes:

- Tesseract .NET wrapper 5.2.0, copyright Charles Weld, Apache License 2.0: https://github.com/charlesw/tesseract
- Tesseract OCR native library, Apache License 2.0: https://github.com/tesseract-ocr/tesseract
- Leptonica native image processing library, BSD-style license: https://github.com/DanBloomberg/leptonica
- English LSTM model from `tesseract-ocr/tessdata_best`, Apache License 2.0: https://github.com/tesseract-ocr/tessdata_best

Model source revision: `e12c65a915945e4c28e237a9b52bc4a8f39a0cec`.
Model SHA-256: `8280aed0782fe27257a68ea10fe7ef324ca0f8d85bd2fd145d1c2b560bcb66ba`.

The English model and license texts are shipped under `tessdata/`. The model is distributed unchanged. No recognition image or text is sent to these projects or any network service.
